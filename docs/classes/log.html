make

  • make(id, options?): null

  • Get or create the child log group with target id. Each log is identified by its full path in the hierarchy, so root.make('a').make('b') has id root.a.b and is a different log than root.make('b'). Calling make repeatedly with the same id from the same log always returns the same instance: a group is only ever created once.

    A dotted id walks the hierarchy one segment at a time, so root.make('a.b') returns the same log as root.make('a').make('b'), creating any missing intermediate groups with default options.

    Parameters

    • id: ""

      id of the child log, relative to this log.

    • Optional options: {
          enabled?: boolean;
          level?: LevelInput | LevelInput[];
      }

      Options applied when the final group is created. Ignored when it already exists.

      • Optional enabled?: boolean
      • Optional level?: LevelInput | LevelInput[]

        Starting group level as a bitmask, level key, or array of either.

    Returns null

    The child log, or null when id is not a valid id.
